# HOVEL Market Research

HOVELの市場調査・テンプレート販売・将来のマイクロM&A探索を一つの仕組みで運用するためのリポジトリです。

## 目的

1. 初期費用を抑えて市場調査商品を販売する
2. 日本と海外の市場間にある情報格差を収益化する
3. 調査過程をテンプレート商品へ転換する
4. 廃業・引退・事業承継案件の知識とネットワークを蓄積する
5. 借金返済に寄与する継続的な副収入を作る

## 優先順位

1. 有料需要の検証
2. 市場調査スプリントの販売
3. 調査テンプレートの販売
4. 廃業・引退案件データベースの構築
5. 紹介・提携・マイクロM&Aへの発展

## 事業構造

```text
無料の公開調査
    ↓
見込み顧客・課題の把握
    ↓
有料の市場調査スプリント
    ↓
再利用可能部分をテンプレート化
    ↓
継続調査・法人契約
    ↓
案件紹介・マイクロM&A
```

## 主要ディレクトリ

- `docs/`：戦略、SOP、商品設計
- `templates/`：調査・競合・レビュー分析の型
- `data/`：市場機会、案件候補、顧客課題の記録
- `.github/ISSUE_TEMPLATE/`：毎週の実行管理

## 90日間の勝利条件

- 有料顧客3件
- 市場調査レポート3本納品
- 販売可能なテンプレート1商品
- 廃業・引退・承継候補100件のデータベース
- ヒアリング20件
- 売上合計100,000円以上

## 運用原則

- 作る前に売る
- 無料情報の要約ではなく、意思決定材料を提供する
- 事実、推測、提案を分ける
- 出典と調査日を残す
- 平日の即時対応を前提にしない
- 在庫、広告、外注へ先に資金を投じない

## 最初に着手するIssue

1. ターゲット候補を3市場に絞る
2. 3つのサービス仮説を作る
3. サンプルレポートを1本作る
4. 販売ページの原稿を作る
5. 見込み顧客20件へヒアリングまたは提案する
