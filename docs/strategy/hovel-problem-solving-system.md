# HOVEL Problem Solving System

## ブランド定義
HOVELは、働く人のパフォーマンスを阻害する問題を、科学と実験によって解決するブランド。

### 初期ターゲット
25〜35歳の男性会社員。

## ミッション
曖昧な悩みを測定可能な問題へ変え、再現可能な解決策を提供する。

## 商品思想
- 売るのは商品ではなく『問題が解決された状態』
- 記事、診断、記録、ツール、商品、サービスを一体で設計する
- マーケティングは価値を届ける増幅器

## 商品開発プロセス
1. Problem Discovery
2. Severity Validation
3. Root Cause Analysis
4. Existing Solution Audit
5. Minimum Effective Solution
6. Productization
7. Measured Improvement
8. Iteration

## Good Product評価
1. 問題強度
2. 改善効果
3. 体感速度
4. 再現性
5. 継続性
6. 競合との差別化
7. 紹介性
8. 模倣耐性
9. 価値対価格
10. 継続可能性

## 優先領域
1. 仕事のパフォーマンス
2. 清潔感・対人印象
3. 意思決定負荷

## 商品エコシステム例
記事→診断→記録→改善提案→推奨商品→効果測定→継続改善
