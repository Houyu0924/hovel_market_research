# 市場調査スプリント SOP

## 0. 受注前確認

- 誰が、何を決めるための調査か
- 対象国、業界、商品
- 期限
- 予算
- 必須の比較対象
- 調査結果を使う場面

調査目的が曖昧な場合は着手しない。

## 1. 調査設計

1. 意思決定を1文で定義する
2. 調査質問を5〜10個に分解する
3. 必要な一次情報と二次情報を決める
4. 調査対象外を明記する
5. 完了条件を決める

## 2. 情報収集

優先順位：

1. 公的機関、業界団体、企業公式情報
2. EC、レビュー、価格ページ
3. 信頼できる調査会社・報道
4. SNS・掲示板は仮説発見用途

各記録に以下を残す。

- URL
- 調査日
- 発行日
- 情報種別
- 要点
- 信頼度
- 利用箇所

## 3. 分析

- 市場規模と成長要因
- 顧客課題
- 競合ポジション
- 価格帯
- 販売チャネル
- レビューの評価理由と不満
- 参入障壁
- 未検証事項

## 4. 結論作成

結論は次の順番で書く。

1. 推奨判断
2. 判断理由
3. 主なリスク
4. 次に検証すること
5. 実行しない選択肢

## 5. 品質管理

- 事実と推測を区別したか
- 重要数値に出典があるか
- 古い情報を最新情報として扱っていないか
- 顧客の意思決定に不要な情報を削ったか
- 断定の強さは根拠に合っているか
- 翻訳で意味を変えていないか
- 個人情報や非公開情報を含めていないか

## 6. 納品後

- 顧客が実際に使った箇所を聞く
- 不足情報を記録する
- 再利用可能部分をテンプレート化する
- 次の商品・継続調査候補をIssue化する

## AI利用ルール

AIは、整理、分類、仮説生成、文章校正に利用する。存在しない数字、引用、企業情報、レビューを生成させない。重要情報は原典で確認する。
